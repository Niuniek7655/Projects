# Program do pobierania danych

## Opis
Program do automatycznego pobierania danych z rejestrów publicznych (np. KRS, CEIDG, KRUS, GUS).

## Zakres funkcjonalny
- Harmonogram pobrań (cron/planer)
- Parsowanie i walidacja danych
- Zapis do bazy danych / eksport CSV
- Obsługa błędów i retry

## Uwagi
Należy uwzględnić limity API i wymogi prawne dotyczące przetwarzania danych publicznych.
